# Sterowanie i zapis

Kierunki joysticka przesuwają robota i pchają jedną skrzynię. Nie można ciągnąć skrzyń. Ustaw wszystkie skrzynie na dokach.

| Wejście | Działanie |
| --- | --- |
| FIRE lub SELECT w grze | Undo, do 256 udanych kroków; puść przycisk przed następnym |
| OPTION w grze | Restart poziomu |
| START | Pauza / wznowienie |
| SELECT w pauzie | Zapis i powrót do menu |
| FIRE w pauzie | Opcje |
| Nowe naciśnięcie FIRE po rozwiązaniu | Następny poziom i automatyczny zapis |

Menu udostępnia BEGIN SHIFT, CONTINUE, wybór poziomu i OPTIONS. W selektorze wybierz poziom i potwierdź. W opcjach góra/dół wybiera pozycję, FIRE zatwierdza; muzyka i SFX mają osobne przełączniki. RESUME GAME wznawia grę. EXIT TO MAIN MENU wymaga potwierdzenia i może utracić niezapisany postęp — nie jest poleceniem zapisu.

Continue odtwarza planszę, liczniki i ustawienia. Zimne Continue ma puste undo. Restart i nowy poziom czyszczą undo. Graj na zapisywalnej kopii właściwej wersji ATR. Nie wyłączaj zasilania ani nie wyjmuj nośnika podczas zapisu; po błędzie ponów próbę. Brak automatycznej migracji zapisów między wersjami. Krótki impuls kierunku podczas kończenia ruchu może zostać pominięty.
