# Jak grać

Gra logiczna Sokoban na Atari 65XE PAL. Steruj robotem serwisowym i przepchnij wszystkie skrzynie na cele. Nie można ciągnąć skrzyń ani pchać dwóch naraz.

| Atari | Działanie |
| --- | --- |
| Kierunki joysticka | Ruch i pchanie |
| FIRE lub SELECT | Undo podczas gry, do 256 udanych kroków |
| OPTION | Restart poziomu |
| START | Pauza; ponowny START wznawia |
| SELECT w pauzie | Zapis i powrót do menu |
| FIRE na ukończonej planszy | Następny poziom i automatyczny zapis |

Przed kolejnym undo zwolnij przycisk. Na ukończonej planszy SELECT nadal cofa ostatni ruch. FIRE w pauzie otwiera konfigurację: lewo/prawo przełącza muzykę, FIRE efekty, START wraca.

Continue odtwarza zapisane pozycje gracza i skrzyń oraz liczniki. Po zimnym wznowieniu historia undo jest pusta. Restart i nowy poziom także ją zerują. Zapis wymaga zapisywalnego ATR, nośnika i D1:. Nie wyłączaj sprzętu podczas zapisu; po błędzie wybierz ponowienie.

Wszystkie **60 układów początkowych ma potwierdzone rozwiązania**. Błędne ruchy mogą jednak zablokować skrzynie. Użyj undo lub restartu; nie trzeba zaczynać całej kampanii.
