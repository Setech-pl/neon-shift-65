# How to play

A Sokoban puzzle game for the Atari 65XE PAL. Guide the service robot and push every crate onto a dock. You cannot pull crates or push two at once.

| Atari | Action |
| --- | --- |
| Joystick directions | Move and push |
| FIRE or SELECT | Undo during play, up to 256 successful steps |
| OPTION | Restart the level |
| START | Pause; START again resumes |
| SELECT while paused | Save and return to the menu |
| Fresh FIRE on a solved board | Next level and automatic save |

Release the button before the next undo. SELECT still undoes on a solved board. FIRE while paused opens configuration: left/right toggles music, FIRE toggles effects, START returns.

Continue restores saved player/crate positions and counters. Undo history is empty after a cold resume. Restart and a new level also clear it. Saving requires a writable ATR, medium and D1:. Do not power off during saving; retry after a reported save error.

All **60 starting layouts have confirmed solutions**. A wrong move can still trap crates. Use undo or restart; you do not need to restart the campaign.
