# Autorzy i pochodzenie

**Marcin Krzetowski (Setech Game Studio)** — właściciel projektu, kierunek, decyzje produktowe, dostarczone referencje i uwagi wizualne, wybór licencji. Brief zapisuje wcześniejszą współpracę z Claude; dostarczony niezależny audyt jest oznaczony jako Claude. Codex pomagał przy implementacji, zasobach proceduralnych, narzędziach kampanii, testach, dokumentacji i przygotowaniu wydania. Dowody nie ustalają indywidualnego ludzkiego autorstwa każdego wygenerowanego piksela, patternu lub mapy; nie przypisujemy go bez podstaw.

Kampania 60 poziomów to niezmieniony plik CAMP2-B; metadata opisują 46 nowych autorskich układów i 14 zachowanych układów CAMP2-B, bez zewnętrznej kolekcji. Wcześniejsze kampanie, prototypy i obrazy referencyjne są historycznymi źródłami o odrębnie opisanym pochodzeniu.
