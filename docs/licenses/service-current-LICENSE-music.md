# Pochodzenie muzyki i zakres licencji

„Service Current” jest nową kompozycją wykonaną dla tej lokalnej kwalifikacji. Osiem64-wierszowych patternów, trzy kanały i szesnaście części aranżacji zapisuje `compile.py`; nie użyto cudzych utworów, sampli, eksportów RMT ani assetów Void Strike. Dane kompozycji `music.nrq` (1552B body) i nowo utworzone dane instrumentów są udostępnione jako CC0-1.0: https://creativecommons.org/publicdomain/zero/1.0/ . Nie opublikowano ani nie wypchnięto tych plików.

Poniższa licencja MIT obejmuje wyłącznie nowo napisany tracker `music_update` przez `_music_end` oraz nowe tablice instrumentów w `hardware.s`. Nie zmienia praw/licencji istniejącego silnika, kodu VBI/SFX pochodzącego z repozytorium, assetów referencyjnych ani całego produktu.
