# NEON SHIFT 65 v1.0.1

60 poziomów w czterech animowanych obszarach industrialnych. Ruch i pchanie joystickiem, undo256, restart, pauza, zapis i Continue. Atari XL/XE PAL, standardowe 64 KB, BASIC OFF.

[Zagraj](https://setech-pl.github.io/setech-arcade/play/neon-shift-65/) · [ATR](https://github.com/Setech-pl/neon-shift-65/releases/download/v1.0.1/neon-shift65.atr) · [Instrukcja](how-to-play.pl.md)

Paczka gracza zawiera jeden normalny ATR, instrukcje PL/EN i licencje. Archiwum źródeł zawiera komplet wejść buildera. SHA256SUMS identyfikuje wszystkie assety wydania.

Potwierdzono odtwarzalny build i zgodność z ATR sprawdzonym w emulatorze, w tym 60/60 poziomów. Test fizycznego Atari/SIO2SD oraz odsłuch właściciela pozostają niepotwierdzone.
